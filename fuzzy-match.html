Fuzzy Match

Free on the Marketplace

Fuzzy VLOOKUP for Google Sheets. Three custom functions that match text the way a person would, forgiving typos, capitals, punctuation and word order.

Install from the MarketplaceRead the how-to guide

The formulas

FUZZYMATCH

The closest value from a clean list, for every row at once.

=FUZZYMATCH(A2:A100, Customers!A2:A, 0.8)

FUZZYLOOKUP

Like XLOOKUP, but fuzzy. Finds the closest row and returns any column from it: an ID, a price, an email.

=FUZZYLOOKUP(A2:A100, Customers!A2:A, Customers!C2:C, 0.8)

FUZZYSCORE

A similarity score from 0 (different) to 1 (same), so you can check or sort your matches.

=FUZZYSCORE(A2, B2)

What it catches

  • Typos: "Inytech" matches Initech
  • Word order: "Corp Umbrella" matches Umbrella Corp
  • Case and punctuation: "ACME Pty. Ltd" matches Acme Pty Ltd
  • Accents and symbols are ignored

No false guesses

Set a threshold between 0 and 1. If nothing is close enough, the cell stays blank instead of guessing wrong. Use 0.9 for strict matching, or 0.7 to catch more.

Pass a whole column and one formula fills it. Exact matches are found instantly and very different lengths are skipped, so thousands of rows take seconds.

Get started

  1. Install

    Add Fuzzy Match free from the Google Workspace Marketplace.

  2. Run "How to use" once

    Open Extensions > Fuzzy Match > How to use once in each new spreadsheet. If a formula shows #NAME?, this is the fix.

  3. Try the example

    Extensions > Fuzzy Match > Insert example sheet adds all three formulas on sample data.

Private by design. Everything runs inside your spreadsheet. The add-on can only access the sheet you use it in, and your data never leaves Google Sheets. See the privacy policy.
