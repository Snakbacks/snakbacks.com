How it works

From install to result in three steps

  1. Install from the Marketplace

    Add the free add-on from the Google Workspace Marketplace. It asks for one permission: access to the spreadsheet you use it in.

  2. Open "How to use" once

    In a new spreadsheet, run Extensions > Fuzzy Match > How to use once. That wakes the formulas up in that file; without it they can show #NAME?.

  3. Use the formulas or the menu

    Type a formula such as =FUZZYMATCH(A2:A100, Customers!A2:A, 0.8), or pick an action from the add-on's Extensions menu.
