How to Remove Duplicates in Google Sheets: 5 Ways

Written with AI assistance; tested in a real Google Sheet.

There are five reasonable ways to remove duplicates in Google Sheets, and they suit different jobs. Pick by whether you want to delete the extra rows, keep the original and show a clean copy, or only mark the repeats. This page is the overview, with links to the detailed guides.

The sample data

Names in A2:A7, row 1 holds a header:

  • Acme
  • Globex
  • Acme
  • Initech
  • Globex
  • acme

Note the last row is lower-case. Whether "acme" is a duplicate of "Acme" depends on the method, as covered below.

Way 1: the built-in Data cleanup tool

Select the range, then choose Data > Data cleanup > Remove duplicates. A dialog asks whether your data has a header row and which columns to compare. Confirm and the extra rows are deleted from the sheet itself, which is permanent apart from Undo. Work on a copy of the tab the first time. Try it on a few differently capitalised rows before relying on it for case. For several columns at once, see Remove Duplicates in Google Sheets by Multiple Columns

Way 2: the UNIQUE function

=UNIQUE(A2:A7)

This returns Acme, Globex, Initech, acme, a clean copy that leaves the original untouched and updates when the source changes. UNIQUE is case-sensitive, so "acme" is kept as its own value. COUNTUNIQUE(A2:A7) also returns 4. To ignore case, lowercase first:

=UNIQUE(ARRAYFORMULA(LOWER(A2:A7)))

This returns acme, globex, initech. For more on case, see Case-Sensitive and Case-Insensitive Match in Google Sheets

UNIQUE with blank rows

If you use a range that runs past your data, such as =UNIQUE(A2:A100), the output includes an extra blank row for the empty cells. Filter the blanks out first:

=UNIQUE(FILTER(A2:A100,A2:A100<>""))

Way 3: flag with COUNTIF, then filter

In B2, filled down to B7:

=COUNTIF($A$2:A2,A2)

This gives 1, 1, 2, 1, 2, 3. A value of 1 is the first appearance, so anything above 1 is a repeat. COUNTIF ignores case, so "acme" counts as the third Acme. To keep only the first of each:

=FILTER(A2:A7,B2:B7=1)

This returns Acme, Globex, Initech. Or select the data and use Data > Create a filter to hide the rows where B is above 1, then delete the visible rows you want gone. Counting rather than removing is covered at How to Count Duplicates in Google Sheets (COUNTIF, QUERY)

Way 4: highlight with conditional formatting

If you only need to see the duplicates, use Format > Conditional formatting, choose Custom formula is, and enter:

=COUNTIF($A$2:$A$7,A2)>1

Every value that appears more than once is shaded, including its first appearance. Nothing is deleted. The full walkthrough, including multiple columns, is at How to Highlight Duplicates in Google Sheets (Formulas)

Way 5: near-duplicates

All four methods above need identical text (with case varying as noted). "Acme Pty Ltd", "ACME Pty. Ltd" and "Acme Pty Limited" are three different values to every method above. Cleaning helps with some: TRIM removes extra spaces, and LOWER removes capital-letter differences. Punctuation and word differences need similarity matching, not formulas. A practical order is to clean first with TRIM and LOWER in a helper column, remove exact duplicates from that column, and only then review what is left by eye or with a similarity score.

Which should you use?

  • One-off cleanup of a copy: Way 1.
  • A live, clean list that updates: Way 2.
  • You need to review before deleting: Way 3 or Way 4.
  • Different spellings of the same thing: Way 5.
