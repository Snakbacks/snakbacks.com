Fuzzy Match Free add-on

Match messy text to a clean list despite typos, case, punctuation or word order, with the formulas FUZZYMATCH, FUZZYLOOKUP and FUZZYSCORE.

About Fuzzy Match · Get it on the Marketplace · Try it online, free

VLOOKUP needs an exact match. Real data is not exact: "ACME Pty. Ltd" in one list, "Acme Pty Ltd" in another, "Inytech" typed for "Initech", "Corp Umbrella" for "Umbrella Corp". The Fuzzy Match Template adds three formulas to Google Sheets that find the closest match anyway.

What you get

  • FUZZYMATCH(values, lookup, [threshold]) returns the closest name from your clean list for every messy name. One formula fills the whole column.
  • FUZZYLOOKUP(values, lookup, return_range, [threshold]) is a fuzzy XLOOKUP: it finds the closest row and returns any column from it, such as an account ID or email.
  • FUZZYSCORE(a, b) returns a similarity from 0 to 1, so you can review borderline pairs yourself.
  • A template sheet with the formulas already installed and a worked example, a copy-and-paste version of the code for your other sheets, and a short PDF guide.

How it behaves

Tested in a real Google Sheet with the included example:

  • "ACME Pty. Ltd" finds Acme Pty Ltd (score 1, punctuation and case ignored)
  • "Inytech" finds Initech (score 0.924)
  • "Corp Umbrella" finds Umbrella Corp (word order ignored)
  • "Wayne Enterprises" stays blank, because nothing in the list is close enough, instead of guessing

The threshold (default 0.8) sets how close a match must be. Raise it to be stricter, lower it to catch looser matches.

Who it is for

  • People whose Google Workspace admin blocks add-ons. There is nothing to install or approve: the code lives in your own sheet.
  • Anyone reconciling two lists: customers, suppliers, products, survey answers.
  • People who want to own and read the code. Nothing is sent anywhere.

Limits

  • It compares how text looks. It cannot know that "Bob" and "Robert" are the same person.
  • Speed: in our tests 1,000 names against a 1,000-name list finished in about 15 seconds. Google stops a custom formula after 30 seconds, so split larger lists into chunks.
  • Google Sheets only, not Excel.
