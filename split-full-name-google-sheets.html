Split First and Last Name in Google Sheets: 4 Methods

Written with AI assistance; tested in a real Google Sheet.

A full name in one cell is awkward to sort, mail-merge or match. This page splits names into first, middle and last with the built-in tool and with formulas, then handles the cases that break simple splits: "Last, First" order, titles and stray spaces.

The sample data

Names in A2 down, row 1 holds headers:

  • Mary Jane Smith
  • John Smith
  • Cher
  • Smith, John
  • Dr. Jane Brown

Method 1: Data > Split text to columns

Select the column, then choose Data > Split text to columns. A separator box appears; pick Space (or Detect automatically). The names split into columns in place and overwrite whatever is to the right, so insert empty columns first. It is a one-off action: if the source changes, nothing updates. Use a formula when the data keeps changing.

Method 2: the SPLIT function

=SPLIT(TRIM(A2)," ")

For Mary Jane Smith this spills three cells: Mary, Jane, Smith. For John Smith it spills two. Rows with different numbers of words give different numbers of cells, so the last name is not always in the same column. That is the reason for the next method. SPLIT drops empty pieces by default, so doubled spaces do not create blank cells, but keep the TRIM, because other functions below do not.

Method 3: first name and last name with fixed columns

First name:

=REGEXEXTRACT(TRIM(A2),"^\S+")

or without regex:

=LEFT(TRIM(A2),FIND(" ",TRIM(A2)&" ")-1)

Both return Mary for Mary Jane Smith, John for John Smith and Cher for Cher. The extra " " added inside FIND stops a one-word name from returning an error.

Last name is the final word:

=REGEXEXTRACT(TRIM(A2),"\S+$")

This gives Smith, Smith and Cher. A single name counts as both first and last. If you want the last name blank for one-word names, wrap it: =IF(ISERROR(FIND(" ",TRIM(A2))),"",REGEXEXTRACT(TRIM(A2),"\S+$")).

Middle names

With first name in B2 and last name in D2, the middle is whatever remains:

=TRIM(MID(A2,LEN(B2)+1,LEN(A2)-LEN(B2)-LEN(D2)))

Mary Jane Smith returns Jane. John Smith returns an empty cell. Several middle names stay together as one string ("Mary Anne Jane Smith" gives "Anne Jane"). This assumes A2 has no extra spaces, so run Method 3 on a cleaned copy.

"Last, First" format

For "Smith, John", split on the comma and trim each piece:

=ARRAYFORMULA(TRIM(SPLIT(A5,",")))

This spills Smith then John. To flip it into a normal "John Smith" in one cell:

=TRIM(REGEXREPLACE(A5,"^([^,]+),\s*(.*)$","$2 $1"))

This returns John Smith. You can then use Method 3 on the result.

Titles

Strip a leading title before splitting:

=TRIM(REGEXREPLACE(A6,"(?i)^(Mr|Mrs|Ms|Miss|Dr|Prof)\.?\s+",""))

Dr. Jane Brown becomes Jane Brown. The \s+ after the title means a name that merely starts with those letters, such as Drew Barry, is left alone. Suffixes such as Jr or III are not handled here; strip them with a similar REGEXREPLACE at the end of the pattern if you have many.

Extra spaces

Leading, trailing and doubled spaces break LEFT, FIND and MID. TRIM removes all of them, and Data > Data cleanup > Trim whitespace does the same to the cells themselves. Text copied from web pages may contain non-breaking spaces (character 160), which TRIM leaves alone. Swap them first:

=TRIM(SUBSTITUTE(A2,CHAR(160)," "))

Limits worth knowing

  • Compound surnames such as "van der Berg" or "De la Cruz" will come out as just the last word. Check them by hand or keep a small exceptions list.
  • Names with only initials ("J. R. Smith") work, but the first name is "J.".
  • Hyphenated names count as one word.
  • No formula can tell which word is the surname in every culture. Treat the output as a first pass and eyeball the odd ones.
