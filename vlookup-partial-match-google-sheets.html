VLOOKUP Partial Match in Google Sheets (Wildcards, Contains)

Written with AI assistance; tested in a real Google Sheet.

VLOOKUP normally needs the whole cell to match. If you search for "Acme" and the list says "Acme Pty Ltd", you get #N/A. To do a partial match, "contains", starts-with or ends-with lookup, you add wildcards. This page shows the formulas, and where partial matching stops working.

The sample data

Master list, D2:E5 (name, ID):

  • Initech, 101
  • Umbrella Corp, 102
  • Acme Pty Ltd, 103
  • Globex Corporation, 104

Search terms go in column A, starting at A2. Row 1 holds headers.

Method 1: VLOOKUP with wildcards (contains)

The asterisk * stands for any run of characters. Put one on each side of your search value:

=IF(A2="","",IFERROR(VLOOKUP("*"&A2&"*",$D$2:$E$100,2,FALSE),""))

The last argument must be FALSE (exact match mode). Wildcards only work in that mode. Matching ignores case.

With A2:A5 = acme, Globex, Wayne, Corp, the results are 103, 104, blank, 102. "Wayne" is not in the list, so IFERROR gives a blank. "Corp" appears in both Umbrella Corp and Globex Corporation, and VLOOKUP returns the first match from the top, so you get 102. It does not warn you that there were two.

The blank check at the start matters. An empty search cell becomes "**", which matches every non-empty cell and returns the first row.

Method 2: starts with, and ends with

Starts with, wildcard on the right only:

=IF(A2="","",IFERROR(VLOOKUP(A2&"*",$D$2:$E$100,2,FALSE),""))

Searching Umb, Corp, glo gives 102, blank, 104. "Corp" is blank because no name starts with it.

Ends with, wildcard on the left only:

=IF(A2="","",IFERROR(VLOOKUP("*"&A2,$D$2:$E$100,2,FALSE),""))

Searching Ltd, corp, Corporation gives 103, 102, 104.

There is also a single-character wildcard, the question mark. "Sm?th" matches Smith and Smyth.

Method 3: XLOOKUP with wildcard mode

XLOOKUP does the same thing with a clearer layout. The final argument, 2, switches on wildcard matching:

=IF(A2="","",XLOOKUP("*"&A2&"*",$D$2:$D$100,$E$2:$E$100,"",2))

Same results as Method 1. The fourth argument, "", is what you get when nothing matches, so no IFERROR is needed.

Method 4: the reverse case, your cell is the longer text

Sometimes the cell holds a long string, such as "Invoice Acme Pty Ltd Sydney", and the master list holds the short name. Wildcards cannot help here, because the wildcard goes on the lookup value, not on the list. Use SEARCH instead, which tests whether each list item appears inside your text:

=IF(A2="","",IFERROR(INDEX(FILTER($E$2:$E$5,ISNUMBER(SEARCH($D$2:$D$5,A2))),1),""))

SEARCH returns a position if the list name is found inside A2, and an error if not. ISNUMBER turns that into TRUE or FALSE, FILTER keeps the matching IDs, and INDEX takes the first. Limit the range to your real data (D2:D5, not D2:D100): a blank cell in the list would count as found everywhere.

On the sample, "Invoice Acme Pty Ltd Sydney" gives 103, "Umbrella Corp refund" gives 102, and "Unknown supplier" gives blank.

When the search text contains * or ?

If your search value itself has an asterisk or question mark, it is treated as a wildcard. Put a tilde in front of each one to make it literal:

=IFERROR(VLOOKUP("*"&REGEXREPLACE(A2,"([*?~])","~$1")&"*",$D$2:$E$100,2,FALSE),"")

Suppose the list has "AxB Ltd" (201) and "A*B Ltd" (202). Searching for A*B without the escape matches AxB Ltd first and returns 201. With the escape it returns 202.

Limits of partial matching

  • Wildcards match text cells. A lookup column of true numbers (101, 102) will not match "*10*". Convert it with a helper column such as =TEXT(D2,"0").
  • Partial matching returns only the first hit, in sheet order. Short search terms like "Corp" give risky results. Sort or lengthen your terms if that matters.
  • It cannot handle typos, different word order or abbreviations. "Inytech" does not contain "Initech", and "Corp Umbrella" does not contain "Umbrella Corp". Wildcards only handle the case where one string is literally inside the other.
  • Extra spaces and punctuation break matches. Run Data > Data cleanup > Trim whitespace first.
